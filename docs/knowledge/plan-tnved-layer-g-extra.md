# План: доп. начисления → префиксы ТН ВЭД (слой G)

**Дата:** 2026-08-29. **D33.**  
Канон: [`customs-payments.md`](./customs-payments.md) · [`plan-tnved-opendata-card.md`](./plan-tnved-opendata-card.md) слой G · overlay [`tnved-layer-g.json`](../../src/lib/ved/tnved-layer-g.json).

## 1. Идея

Собрать «дополнительные» начисления (акциз, утильсбор ТС, **экосбор РОП**, НТМ) и привязать к **существующим** кодам/префиксам справочника `TnvedCode` — как **триггеры** на карточке (`measuresHint`), без выдуманных ставок и без scrape.

## 2. Анализ

| Платёж | НПА | Привязка к ТН ВЭД | В смете LBM |
|--------|-----|-------------------|-------------|
| Акциз | НК ст. 181 / 193 | префиксы (алкоголь, **2202** сладкие напитки, табак/ЭСДН, топливо, авто, виноград) | hold (флаг) |
| Утильсбор | ПП 1291 / 81 | 8701–8706, 8716, 8429… | hold (флаг) |
| **Экосбор РОП** | ПП **2414** (+ ставки 1041) | электроника/накопители, АКБ, шины, упаковка, одежда/обувь… | **новый** флаг `ecoFeePossible` |
| НТМ | ЕЭК перечень | главы 01–03, 28, 29… | hold (флаг) |
| Таможенный сбор / НДС | ПП 1637 / НК | не по «группе товара» (шкала ТС / 22%) | уже слой C |

Сахар-песок (1701) **не** акциз. Сладкий напиток → ориентир **2202** (не весь 2202 = объект; флаг = «возможно»).  
SSD/HDD/флеш → **8471 / 8523** и соседняя электроника → экосбор РОП, не утильсбор авто.
