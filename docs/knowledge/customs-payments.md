## Таможенная стоимость без доставки

**MVP (D27):** смета **без международной логистики**.  
`goodsRub` = инвойс × курс (USD/CNY/EUR из настроек) × запас **+2%** (`ved.fxBufferPct`).  
ТС = инвойс (FOB), **не CIF**. Итог без фрахта = товар + пошлина + НДС + сбор (+ прочие сборы брокера).  
Снимок: `aiDraft.landedWithoutFreight`. Код: [`src/lib/ved/landed-cost.ts`](../../src/lib/ved/landed-cost.ts). План: [`plan-landed-without-freight.md`](./plan-landed-without-freight.md).

Не копируем чужие ставки фрахта / агента / оформления. Live ЦБ — follow-up. Shipping UI остаётся выкл.

## Инварианты для агентов

1. Default VAT в draft = **22**, не 20.  
2. AI draft fee = **шкала ПП 1637**, не магические 8–18k из старых rules (поле `feeRub` в rules — legacy hint).  
3. Акциз в базе НДС пока **0** (нет модели).  
4. Утильсбор / НТМ не обещать в CTA (D27).  
5. Полный эталон ставок — NSI/лицензия; без ключей работаем на TWS + НК + ПП.
